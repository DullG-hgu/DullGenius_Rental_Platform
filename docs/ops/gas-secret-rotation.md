# 외부 대여 신청 폼 — 공유 시크릿 교체 절차

행사·단체 대여 신청(구글 폼)은 Google Apps Script(GAS)가 받아서 DB 함수 `ingest_rental_request`로 넘긴다.
이때 GAS가 보내는 **공유 시크릿**이 DB에 저장된 값과 같아야 접수된다. 이 문서는 그 값을 바꾸는 방법이다.

> 관리자 화면에는 이 값을 바꾸는 메뉴가 없다(일부러). 값은 DB와 GAS 두 곳에 있고, 둘을 **같이** 바꿔야 한다.
>
> GAS 원본 코드: 저장소 `scripts/apps_script_form_handler.gs` (전송 결과를 `[Supabase] <코드> <응답>` 로 실행 로그에 남긴다)

## 언제 바꾸나

- Apps Script 프로젝트나 Supabase 프로젝트에 접근할 수 있던 사람이 운영진에서 빠졌을 때
- 값이 채팅·문서·스크린샷 등에 노출됐다고 의심될 때
- 그 외 정기 교체는 필요 없다

## 필요한 권한

- **Supabase** 프로젝트 대시보드 접근 (Table Editor)
- 신청 폼에 연결된 **Apps Script** 프로젝트 편집 권한 (폼 소유 구글 계정)

## 순서 (10분 이내, 폼 신청이 뜸한 시간에)

두 곳을 바꾸는 사이에 들어온 신청은 「인증 실패」로 DB에 안 들어온다.
신청 내용 자체는 구글 폼 응답(시트)에 남고, 운영진 알림 메일도 그대로 온다. 관리자 화면엔 직접 등록 기능이 없으니, 사이에 들어온 건은 응답 시트를 보고 운영진이 신청자에게 직접 연락해 처리한다.

1. **새 값 만들기** — 64자 정도의 무작위 문자열.
   비밀번호 관리자의 생성 기능을 쓰거나, 터미널이 있으면 `openssl rand -hex 32`.
   새 값은 어디에도 붙여 두지 말고 아래 두 칸에만 넣는다.
2. **DB 값 교체** — Supabase 대시보드 → Table Editor → `private_config` 테이블
   → `key` 가 `gas_shared_secret` 인 행의 `value` 를 새 값으로 바꾸고 저장.
   (행이 없으면 같은 key 로 새 행 추가)
3. **GAS 값 교체** — Apps Script 편집기 → ⚙️ 프로젝트 설정 → 스크립트 속성
   → `SUPABASE_GAS_SECRET` 값을 같은 새 값으로 바꾸고 저장.
   **앞뒤 공백·줄바꿈이 섞이지 않게** 붙여 넣는다(예전에 이것 때문에 실패한 적이 있다).
4. **확인** — 폼에 테스트 신청을 하나 넣고, 관리자 「📝 외부 대여 신청」 탭에 뜨는지 본다. 확인 후 테스트 건은 반려.

## 안 될 때 — Apps Script 실행 로그의 응답으로 구분

| 응답 | 뜻 | 할 일 |
|---|---|---|
| `인증 실패` | DB 값과 GAS 값이 다름 | 2·3번 값을 다시 똑같이 (공백 확인) |
| `서버 시크릿 미설정` | DB에 `gas_shared_secret` 행이 없음 | 2번에서 행 추가 |
| HTTP 401 | 시크릿이 아니라 **Supabase 키** 문제 | 스크립트 속성 `SUPABASE_PUBLISHABLE_KEY` 가 `sb_publishable_` 로 시작하는 현재 키인지 확인 |

## 폼 질문을 고칠 때

GAS는 질문 **제목**에 든 낱말(예: 「단체명」, 「대여기간」, 「수령」)로 답을 찾는다.
제목을 크게 바꾸면 그 칸이 빈 값으로 들어간다. 바꾼 뒤에는 테스트 신청을 하나 넣고
Apps Script 실행 로그에 `[extractAnswers] 매칭 실패` 가 없는지 본다. 있으면 `.gs` 의
`FORM_FIELD_PATTERNS` 에 새 제목의 낱말을 넣고 콘솔에 다시 붙여 넣는다.
선택지 문구(개수·기간)를 바꾸면 GAS가 아니라 DB의 `_parse_*` 함수 쪽이다.
답변 원문은 제목이 바뀌어도 `raw_payload.answers` 에 전부 남는다.

## 하지 말 것

- 새 값을 단톡방·노션·git·이 문서에 적지 않는다
- 프런트엔드 환경변수(`VITE_…`)에 넣지 않는다 — 넣으면 사이트를 여는 누구나 볼 수 있다
- DB 값만 바꾸고 GAS를 안 바꾸면 그때부터 모든 신청이 조용히 안 들어온다. 반드시 4번 확인까지
